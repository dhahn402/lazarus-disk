The honest version

What actually changes

No exaggerated numbers here. This is what a refresh realistically does, and I measure your machine before and after so you can see it yourself.

Before

  • Two to four minutes from power button to usable desktop
  • Years of trial software and update leftovers running at startup
  • An operating system no longer getting security updates
  • A mechanical hard drive doing all the work
  • Fans loud enough to hear from the next room

After

  • Typically well under a minute to a working desktop
  • A clean, current system with free security updates for years
  • Your files, photos and bookmarks moved across and checked
  • Browser, email, printer and Wi-Fi set up and tested
  • AI tools matched to what the hardware can honestly run

Scope of work

What you’re paying for

Backup first
Nothing is erased until your files are copied and I’ve confirmed the copy opens. Photos, documents, browser bookmarks and saved passwords. This step happens before anything else, every time.
Fresh system
A clean install of Linux — usually Pop!_OS. It’s free, it gets security updates, it runs well on hardware Windows has outgrown, and there’s no license to buy or subscription attached.
Hardware check
I test the drive, memory and battery and tell you what I find. If a part is failing, you’ll hear it before I do any work — not after.
Everyday software
Browser, email, word processor and spreadsheet, photo viewer, video calls, printer and Wi-Fi. All configured and tested with you, not just installed.
AI setup
Where the hardware supports it, a private assistant that runs on your own machine with no account and no data leaving the house. Where it doesn’t, I set up the free web tools and show you how to use them.
Shown, not just handed back
I sit with you and walk through it — where your files went, how to update, how to use the AI. Plus a printed page of the basics to keep near the machine.

Setting expectations

What I won’t promise you

Plenty of shops will tell you anything to get the machine on the bench. Here’s where the limits honestly are:

  • A refresh won’t make a 2012 laptop match a new one. It makes it pleasant to use again — that’s a real difference, but it’s a different claim.
  • Most older machines have no graphics card worth using for AI, so local models answer at roughly reading speed. Useful for writing and summarizing; not for generating video.
  • Under 8 GB of memory, running AI on the machine itself isn’t realistic. I’ll say so and set up the free web tools instead — the computer still gets much faster.
  • Linux isn’t Windows. If you depend on one specific Windows-only program, tell me first and we’ll check it works before you commit to anything.
  • Some machines aren’t worth the money. If yours is one of them, I’ll tell you and charge you nothing for the look.
